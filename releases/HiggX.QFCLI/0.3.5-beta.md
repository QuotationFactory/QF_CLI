# Quotation Factory CLI v0.3.5-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.3.5-beta - 2026-09-03

### Fixed
- **Browser login with a stale confidential (M2M) client_id.** `qfc auth login` no longer sends a confidential/machine-to-machine `Auth0ClientId` configured in `settings.json` (for example one left behind by an older CLI). Such an app has no loopback callback, so Auth0 rejected the login with "Callback URL mismatch", which is why login could fail on one machine while working on another. The interactive flow now detects the accompanying client secret and falls back to the built-in interactive app, and prints a one-line notice on how to clean up `settings.json`. Unattended auth continues to use `QFC_CLIENT_ID`/`QFC_CLIENT_SECRET`.
- **`.env.example` missing from the release bundle.** The `qfc-cli.zip` release asset now includes the `.env.example` configuration template (previously excluded by a `.gitignore` rule and an omission in the release packaging step).
