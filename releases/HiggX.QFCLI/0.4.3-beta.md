# Quotation Factory CLI v0.4.3-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.4.3-beta - 2026-10-23

### Added
- **New `understand-scsn-document-types` concept guide.** Explains the goal/function of each SCSN message type, its **process context** (what it starts, what it responds to, what closes a flow), and the **UBL party model** — buying party (`BuyerCustomerParty`) and selling party (`SellerSupplierParty`), plus invoice/despatch aliases — with the **author/sender → receiver** stated for every document. Covers the UBL-based messages (Order, OrderResponse, DespatchAdvice, RequestForQuotation=`quotation`, Quotation=`quotationresponse`, Catalogue, Forecast, Invoice via EN16931) and the SCSN-specific documents in detail (Order Status, Bill of Materials, TPD Package, Measurement), with their roots, key fields, and R26.0 schema basis. Referenced from `qf-scsn`, `qf-scsn-webhook`, `qf-quotations`, `qf-projects`, and `qf-guide-project-states`.
- **`qf-scsn`: browse the SCSN inbox / outbox.** New "Browse the inbox / outbox" section with worked, UAT-verified examples: list received messages (`/docsexchanger/v1/parties/{partyId}/messages?direction=Inbound`) and sent messages (`direction=Outbound`), open a message for detail, download its UBL document (`…/messages/{id}/content`), and list/download attachments (`…/attachments`, `…/attachments/{attachmentId}`). Reconciles the earlier "no dedicated inbox endpoint" note — the `/messages` log is the inbox/outbox, while the backend incoming-exchange lists show the business objects received documents became. Skill description updated so it is selected for "see received/sent SCSN messages" requests.
