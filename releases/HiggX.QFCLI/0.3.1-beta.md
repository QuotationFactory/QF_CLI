# Quotation Factory CLI v0.3.1-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.3.1-beta - 2026-08-31

### Fixed
- **M2M token reuse.** Service credentials persisted with `qfc auth login --client-id` now reuse an environment-isolated access token across CLI processes until shortly before expiry. A cross-process lock prevents concurrent commands from issuing duplicate Auth0 exchanges, and credential, audience, domain, or environment changes invalidate or select the correct cache.

### Security
- Persistent user tokens, refresh tokens, service credentials, and M2M token caches use current-user DPAPI encryption on Windows and migrate existing plaintext files after a successful read. Other platforms retain owner-only storage (`0600` files and `0700` profile directory) with an explicit warning when OS-backed encryption is unavailable. Environment-provided service credentials remain diskless.
