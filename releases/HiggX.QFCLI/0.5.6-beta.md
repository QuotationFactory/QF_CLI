# Quotation Factory CLI v0.5.6-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.5.6-beta - 2026-11-21

### Added
- **Supplier outsourcing / supply chain is now a first-class part of the CLI** (MetalHeaven PR 7980, "Supplier Outsourcing and SCSN"; live on **dev + uat** behind the per-party `showSupplierOutsourcing` workspace flag, off on prod). It replaces the old price-request outsourcing with a full UBL **RequestForQuotation → Quotation → Order** exchange with suppliers over an **omni-channel** transport — **SCSN** (`Scsn`), **email** (`Email`) and the **app-specific link** (`Manual`).
  - **New skill `qf-supply-chain`** — you as the UBL **buying party**: list a project's suppliers (`ProjectSuppliers`), send outgoing RFQs + supplier requests, receive supplier quotations (`IncomingQuotation`), place outgoing orders, and track measurement certificates. Documents the omni-channel channel/endpoint model and the feature flag.
  - **New skill `qf-supplier-rfq`** — you as the UBL **selling party** (the supplier): the supplier RFQ inbox (`SupplierRfqInbox`), responding/submitting a quote via the public, token-authenticated app-link endpoints (`SupplierRfqResponse` — `GET`/`PUT`/`POST /api/public/rfq-invitations/{id}?token=`), and supplier team management (`SupplierTeam`).

### Changed
- **MCP surface map (`Mcp/SurfaceMap.cs`):** 21 new/renamed backend tags (emitted by dev + uat behind the flag) are now mapped instead of falling back to `base`. `procurement` → `ProjectSuppliers`, `OutgoingRequestForQuotation`, `IncomingQuotation`, `RfqSpecifications`, `SupplierRfqInbox`, `SupplierRfqResponse`, `SupplierTeam`; `rfq` → `IncomingRequestForQuotation`; `quotation` → `OutgoingQuotation`, `EmailCounterparty`; `order` → `Orders`, `ManualOrderExchange`, `MeasurementCertificates`, `CloudExport`; `platform-config` → `ServiceAccounts`, `CloudExportSettings`, `ReadinessRates`; `portal-config` → `CustomerPortalUsers`; `system` → `SystemPartyUsers`, `RfqImportInvestigation`; `base` → `ArtifactAccess`. The `procurement` surface is re-themed **"Procurement & supply chain"** and now carries both the buy-side and the supplier-side endpoints. **Known tags 121 → 142.** Legacy prod price-request tags are kept for backward compatibility.
- **qf-suppliers** refreshed to the live 15 `SupplierManagement` endpoints (incl. `details`, `exchange-channels`, `legal-identity`, `active-rfqs`, `CanEditLegalIdentity`) and cross-links the new outsourcing skills.
- **qf-quotations** cross-links `qf-supply-chain` / `qf-supplier-rfq`, adds `batch-size-variants` and `exchange-capabilities`, and drops the stale price-request data structure.
- **qf-cli** skill map gains a "Supply Chain & Document Exchange" section; **CLAUDE.md** indexes the two new skills.
- **Document Exchange on uat** is confirmed formally defined and live (41 endpoints) — the `scsn-cli-analysis.md` note that marked uat as derived/502 is corrected.
