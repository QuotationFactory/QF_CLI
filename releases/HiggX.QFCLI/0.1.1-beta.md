# Quotation Factory CLI v0.1.1-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.1.1-beta - 2026-08-23

### Added
- **`list_skills` / `get_skill` tools.** Agents can now obtain the qf-* workflow skills as *tools* (not only as prompts): `list_skills` returns the in-scope skills — optionally filtered by keyword — and `get_skill` returns a skill's full workflow to follow, then execute via `call_api`. The server instructions point agents at them for multi-step tasks. (Prompts remain for human-driven clients.)
- **Skills embedded in the assembly.** The qf-* skills are compiled into the `qfc` binary and served by the MCP server from there, so a deployed or containerized server ships with its skills and needs no `.claude/commands` folder at runtime. The `mcp --skills-dir` option still overrides with on-disk files for development.
- **Reference-guide skills converted to proper skill format.** The `understand-settings-*` concept guides and `qf-settings-*` workflows now carry YAML frontmatter (`name` + `description`) at the top: 6 files whose frontmatter sat *after* a leading comment (so neither the MCP server nor the Claude Code harness parsed it) are fixed, and 38 frontmatter-less concept guides get a proper description. All 87 skills are now correctly parsed and exposed via `list_skills`/`get_skill` and the prompts. The loader also synthesizes a description from the first heading as a fallback for any future frontmatter-less skill.
