# Quotation Factory CLI v0.5.5-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.5.5-beta - 2026-11-21

### Changed
- **Synced with the channel-neutral Document Exchange API (live on dev + uat).** The Document Exchange Inbox/Outbox now holds email documents next to SCSN messages (per party, behind the `documentExchangeAllChannels` flag).
  - **qf-scsn** documents the new endpoints: `GET /endpoints`, `GET /attention-count`, `GET /messages/{id}/email-body`, `GET /messages/{id}/raw-email`, `POST /messages/{id}/triage`, `POST /messages/{id}/reclassify` and `POST /messages/{id}/add-to-project`. It also covers party quarantine (`GET /quarantine`, `POST /quarantine/{id}/release-request`) and system-admin quarantine (`/docsexchanger/v1/admin/document-exchange/quarantine` list/release/delete). It adds the new `channel` / `triage` list filters, the channel-neutral message fields, the `Delivered` status, and the `autoProcessIncomingUblDocuments` → `autoProcessIncomingDocuments` rename.
  - **MCP surface map:** the new `DocExchangeQuarantine` tag maps to `order` and `DocExchangeAdminQuarantine` maps to `system` (121 known tags).
  - **qf-scsn-webhook:** documents the new webhook payload fields (`channel`, `format`, `endpointAddress`, `subject`, `emailBodyUrl`, `rawEmailUrl`). Email documents are delivered to the party's first live agent webhook, and a delivered inbound event marks the message Handled.
  - **qf-users** documents the `documentExchangeAllChannels` party flag. **qf-quotations** documents the `documentExchangeMessageId` field on incoming RFQs.

### Fixed
- **`qfc scsn listen --pull` handles email rows.** It saves an email row's content as `document.eml` instead of `document.xml` and also saves the decoded body (`emailBodyUrl`) as `email-body.json`. Logged events now include `channel` and `format`.
