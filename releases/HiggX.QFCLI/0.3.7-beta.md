# Quotation Factory CLI v0.3.7-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.3.7-beta - 2026-09-03

### Fixed
- **`qfc serve` auto-auth now works on UAT (and dev).** The reverse proxy seeds the web app's Auth0 session for the served environment's SPA client_id (`VITE_AUTH0_CLIENT_ID`, which differs per environment). Previously only the prod and local SPA client_ids were seeded, so serving the UAT web app left its SPA without a session — it fell through to an interactive Auth0 login whose localhost callback isn't whitelisted, showing "Callback URL mismatch". All environments' web-app SPA client_ids are now seeded (auth0-react reads only its own, so the extra entries are harmless).
