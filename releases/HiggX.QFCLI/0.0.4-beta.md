# Quotation Factory CLI v0.0.4-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.0.4-beta - 2026-08-03

### Added
- `dist/README.md` with winget installation guide (`winget install Higgx.QFCli`) and mermaid architecture diagram.
- Markdownlint pre-commit hook (`.githooks/pre-commit`) that lints staged skill files before commit.
- `.markdownlint.json` config tuned for skill file conventions.

### Changed
- Added language tags to 79 bare code fences across 30 skill files for better LLM comprehension.
- Fixed 7 setext headings to ATX style in settings skills.
- Auto-fixed blank lines around headings, lists, fences, and tables in 70 skill files.
