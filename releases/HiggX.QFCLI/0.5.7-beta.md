# Quotation Factory CLI v0.5.7-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.5.7-beta - 2026-11-25

### Changed
- **qf-scsn: diagnose outbound documents that were "Not sent".** A document that fails validation before sending (for example on an SCSN R26 Schematron rule) is a `Failed` **preparation** with no message id. It is not an Outbox message, so it never appears in `GET …/messages?direction=Outbound`. The skill now shows how to find it (`GET …/preparations`), download the staged XML (`GET …/preparations/{id}/content`), and explain the failure line by line instead of repeating the Schematron text.
  - Documents the new `amountDiagnostics` field that newer docsexchanger builds return on a failed preparation and on `POST …/messages/{id}/validate`: per failing line the quantity, price, base quantity, expected vs. stated amount, a `cause` (`BaseQuantityIgnored` | `UnitMismatch` | `MissingValue` | `AmountMismatch`), the implied conversion and suggested fixes with corrected values. Agents should read it first and recompute by hand only when it is missing.
  - Documents the exact R26 line-amount formula (`Quantity × (PriceAmount + charges − allowances) ÷ BaseQuantity × OrderableUnitFactorRate` + sub-lines, rounded to cents) and the header rule (`AnticipatedMonetaryTotal/PayableAmount` = sum of line amounts), with a worked example. In that example, sheets ordered in pieces (`C62`) were priced per 1000 kg (`KGM`), and both fixes are given with corrected values.
  - Two new rows in the error table: "Not sent" but missing from `/messages`, and the R26 line-amount error.
