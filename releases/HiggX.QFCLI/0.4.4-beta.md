# Quotation Factory CLI v0.4.4-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.4.4-beta - 2026-10-23

### Fixed
- **`qf-quotations` endpoint accuracy (stale RFQ / quotation / price-request paths).** The skill referenced endpoints that no longer exist in the backend API, so `api validate-skills --check-schemas` flagged 28 missing paths. Corrected to the current API:
  - RFQs: `/api/parties/{partyId}/rfq…` → `/api/parties/{partyId}/request-for-quotations…` (now split `incoming`/`outgoing`; convert via `…/request-for-quotations/incoming/{rfqId}/create-project`).
  - Quotations: the bare `…/quotations` list and `…/quotations/{id}/DownloadUbl` → `…/quotations/outgoing` / `…/quotations/incoming` and `…/quotations/outgoing/{quotationId}/document` (there is no `DownloadUbl` endpoint; the generated UBL/SCSN set comes in the project zip).
  - Outsourcing: the removed `…/price-request…` family (project / outgoing / incoming price requests) → **outgoing RFQs with supplier requests** (`…/request-for-quotations/{rfqId}/supplier-requests`, `/additional-supplier-requests`, `…/outgoing/{rfqId}/send`) and the supplier side under `/api/supplier-rfqs/…`.
- **`qf-projects`**: fixed the stale `…/rfq/{id}/CreateProject` and `…/quotations/{id}/DownloadUbl` references to the current paths.
- `qf-quotations` now validates with **0 missing endpoints** against the backend spec.
