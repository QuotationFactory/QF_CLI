# Quotation Factory CLI v0.4.5-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.4.5-beta - 2026-11-11

### Changed
- **SCSN tag rename + expanded Document Exchange surface (dev + uat).** The backend renamed the SCSN/Document Exchange OpenAPI tags and the Document Exchange API grew from 14 to 26 endpoints (verified live, identical on dev and uat). Updated the MCP `SurfaceMap` so SCSN endpoints keep their intended scoping instead of silently falling back to the always-visible `base` surface:
  - Backend: `ScsnBrokerAgentManagement` → **`DocExchangeAgentManagement`** (system tier).
  - Document Exchange: `ScsnBroker`/`ScsnBrokerSandbox`/`ScsnBrokerWebhooks` → **`DocExchange`**/**`DocExchangeSandbox`**/**`DocExchangeWebhooks`**, plus two new tags **`DocExchangePreparations`** and **`DocExchangeProcessing`** (all order/contributor tier).
- **`qf-scsn` skill**: documented the new Document Exchange capabilities — outbound **preparations** (stage a document + duplicate decision), inbound **processing** (`process`/`processing`, link to a **relation** + automation), **limits**, legacy-agent **migration**, and the new `/messages` filters (`search`, `statusGroup`). Updated tag names in the authorization and known-values tables.
- **`qf-scsn-webhook` skill**: added a pointer to the inbound processing/relation endpoints for turning received messages into Quotation Factory projects.
