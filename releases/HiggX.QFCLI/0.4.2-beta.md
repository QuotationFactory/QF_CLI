# Quotation Factory CLI v0.4.2-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.4.2-beta - 2026-10-23

### Changed
- **SCSN Document Exchange is confirmed on UAT (now the primary SCSN environment).** The Document Exchange API — the Quotation Factory-fronted SCSN surface at `https://api-uat.rhodium24.io/docsexchanger` (tags `ScsnBroker`, `ScsnBrokerSandbox`, `ScsnBrokerWebhooks`) plus the backend `/api/.../scsn/...` endpoints (`ScsnDocuments`, `ScsnBrokerAgentManagement`, `SCSNManagement`) — is deployed and verified live on `uat`. `QfEnvironment` now formally defines `DocsExchangerBaseUrl` for `uat`, so `--service docsexchanger` resolves it without the "unconfirmed" warning and `qfc mcp` auto-merges its spec. `dev` and `uat` are both confirmed; `prod` is still pending (derives the URL by convention and warns until deployed).
- **Clarified that the CLI only ever talks to the Quotation Factory API.** SCSN document exchange goes entirely through the QF backend host (`api-{env}.rhodium24.io`, `/docsexchanger` and `/api/.../scsn/...`). The network-facing SCSN adapter (`scsn-{env}.rhodium24.io/1.0.3/*`) is called only by the SCSN broker to deliver inbound documents and is never contacted by the CLI. The signed inbound webhook (`X-QF-*`) is emitted by the QF Document Exchange API, not by the SCSN network.

### Fixed
- **`qf-scsn` / `qf-scsn-webhook` skills updated for UAT.** Examples now target `--env uat`; the "DEV only" banners are replaced with "dev and uat (uat primary)". Corrected the `MessageType` set on `send` to the full server-validated list (`order`, `orderresponse`, `orderstatus`, `invoice`, `tpdpackage`, `bom`, `quotation`, `quotationresponse`, `despatchadvice`, `measurement`, `forecast`, `whatif`, `whatifresponse`, `productspecification`, `pricecatalogue`, `pricecatalogueresponse`) with outbound-vs-inbound notes, and updated the SCSN address examples to the current `urn:scsn:qfex:…` agent/message form (configuration `senderAddress` remains the bare `urn:scsn:…` variant).
