# Quotation Factory CLI v0.3.8-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.3.8-beta - 2026-09-28

### Fixed
- **`qfc api delete` now sends its request body.** The `delete` command accepted `--body`/`--body-file` but only attached the content on POST/PUT requests, so DELETE calls went out with no payload and no `Content-Type` and the server rejected them with **HTTP 415 Unsupported Media Type**. System endpoints that take their target in a DELETE body now work, including `DELETE /api/system/partymanagement` (delete a party by `partyId`) and `DELETE /api/parties/{partyId}/usermanagement` (remove a member by `userId`).
