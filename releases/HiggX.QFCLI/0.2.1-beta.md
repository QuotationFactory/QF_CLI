# Quotation Factory CLI v0.2.1-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.2.1-beta - 2026-08-27

### Fixed
- **Renewable browser authentication.** Stored access tokens are refreshed up to five minutes before expiry, and rotating refresh tokens are persisted atomically. A cross-process lock prevents concurrent CLI jobs from consuming the same rotating refresh token; waiting processes re-read the credentials produced by the first refresher.
- **Persistent-login diagnostics.** `qfc auth status` reports whether a refresh token is available, browser login no longer treats a valid but non-refreshable manually copied token as a complete persistent login, and refresh failures provide actionable, sanitized guidance without exposing OAuth responses or credentials.

### Changed
- Interactive documentation now recommends `qfc auth login` for renewable credentials. `qfc auth set-token` and `QFC_ACCESS_TOKEN` remain available as non-refreshable manual fallbacks.
