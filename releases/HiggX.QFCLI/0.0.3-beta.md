# Quotation Factory CLI v0.0.3-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.0.3-beta - 2026-07-24

### Added
- Imported 44 settings skills: 5 `qf-settings-*` workflows (resource sync, auto-assign materials, material-standard selection, organization profile, working-step routes) and 39 `understand-settings-*` per-page reference guides.
- Headless business-rule authoring via the new `/xml` round-trip (`GET`/`POST .../businessrules/{ruleEditorId}/xml`), server-validated through the CodeEffects engine, documented in `qf-business-rules` and `qf-settings-auto-assign-materials`.
- `build/pack.ps1` packaging script with an explicit file manifest, and a `.env.example` configuration template.

### Changed
- Corrected the systemic `partTypeId` vs BOM row `id` guidance across BOM-item skills — item write endpoints (workingsteps, items/delete, pdfviewer, material keywords) require `partTypeRows[].partTypeId`, not the row `id`.
- `--dry-run` validation and `validate-skills` now match endpoints template-aware, so a concrete value filling a `{param}` segment validates against the templated spec path.
- Fixed documented request shapes: project status change requires `initialStatus`+`targetStatus`; `qf-users` uses lowercase `/api/user`; plus several settings endpoint/method corrections.

### Fixed
- `qfc api` now surfaces the full HTTP error body (previously truncated and nulled out on 500 responses).
- `qfc auth login` reports a clear, actionable error when the OAuth callback port is in use or inside a reserved range, instead of crashing with an unhandled exception.
