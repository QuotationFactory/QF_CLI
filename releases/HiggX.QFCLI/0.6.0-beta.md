# Quotation Factory CLI v0.6.0-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.6.0-beta - 2026-11-28

### Added
- **Host the qf-* skills over MCP via the SEP-2640 "Skills over MCP" extension.** The `qfc mcp` server now serves the bundled qf-* skills to clients through the `io.modelcontextprotocol/skills` extension (`skills/list`, `skills/get`, and `skill://…` files over `resources/read`), so a SEP-2640-aware client (recent Claude Desktop / Claude Code) discovers and auto-updates the skills straight from the server with **no local install** — the skills travel and version with the binary, and per-file `sha256` digests drive re-fetch.
  - This runs **alongside** the existing exposure of skills as MCP prompts, so prompt-only clients keep working. `skills/list` is scoped to the caller's access tier, matching the prompt scoping.
  - New `Mcp/McpSkillPackaging.cs` wraps each single-file skill as an `McpServerSkillPackage` with a synthesized canonical `SKILL.md` (double-quoted frontmatter the SDK reader accepts); names are normalized to the Agent Skills naming rule and any unpackageable skill is skipped with a warning so one bad skill never stops the server.
  - New `--no-skills` flag on `qfc mcp`, independent of `--no-prompts`. Works on both stdio and Streamable HTTP transports.
  - Upgrades the MCP C# SDK 2.2.0 → 2.4.0 and adds `ModelContextProtocol.Extensions.Skills` 2.4.0. See `docs/MCP_SKILLS_HOSTING.md`.
