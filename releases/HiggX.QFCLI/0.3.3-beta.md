# Quotation Factory CLI v0.3.3-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.3.3-beta - 2026-09-01

### Added
- **Verified release installer.** `build/install-release.ps1` downloads a selected Windows GitHub release, verifies the published SHA-256 checksum, resolves the Winget executable target, and replaces it safely. Use `-WhatIf` to validate without installing.

### Changed
- **Safer project-creation skill.** Project workflows now resolve the active party from `whoami`, use party-specific selectable terms, submit nested JSON through `--body-file`, and handle service-account identity responses without relying on hardcoded party IDs.
- **Cleaner login output.** Successful browser and M2M login responses no longer include the verbose `note` field.
