# Quotation Factory CLI v0.3.6-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.3.6-beta - 2026-09-03

### Fixed
- **Browser login always uses the built-in interactive app on the hosted tenant.** `qfc auth login` now uses the built-in Native Auth0 application for the browser (PKCE) flow whenever the tenant is the shared hosted one (`auth.rhodium24.io`), across all environments (`prod`, `uat`, `dev`). Previously it only overrode a configured client_id when a client *secret* was also present; a bare stale `Auth0ClientId` in `settings.json` (e.g. left by an older CLI) would still be used and rejected by Auth0 with "Callback URL mismatch". Custom Auth0 tenants continue to use their configured client_id.
