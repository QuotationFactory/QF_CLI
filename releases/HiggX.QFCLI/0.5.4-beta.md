# Quotation Factory CLI v0.5.4-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.5.4-beta - 2026-11-21

### Fixed
- **`qfc serve` no longer breaks uploads / body POSTs with a 500.** The reverse proxies (the Manufacturing Toolkit UI proxy, and the Quotation Factory catch-all + SignalR proxies) forwarded request bodies via `StreamContent` over the non-seekable ASP.NET `Request.Body` **without a Content-Length**, so HttpClient sent them **chunked** — and the Azure hosting in front of the QF and MTK APIs rejects a chunked request body with a plain-text `500 "Backend call failure"`. Every upload and body POST through `qfc serve` failed (e.g. dropping a PDF in the Manufacturing Toolkit "Drawing to MBD" app returned 500). A shared helper (`Serve/ProxyBody.CopyRequestBodyAsync`) now always forwards a Content-Length (copying the client's when known, buffering to measure it when the client sent none, never chunked). Direct `qfc api` calls were unaffected. The `ByteArrayContent` capture branch, `ScsnCommands`, and the CLI multipart uploads already carried a length and are unchanged.

### Documentation
- Added `docs/drawing-to-mbd-agent-retrospective.md` — how a coding agent drives the Manufacturing Toolkit "Drawing to MBD" flow (the build/compare/finish loop, hard-won lessons, prioritized tooling needs, a next-agent playbook, and a regression set of test drawings with baselines).
- Added `docs/auth0-cli-messenger-authorization.md` — an ALM handoff to authorize the CLI's Auth0 client for the Interkwam Messenger API audience, so `qfc cs` works from a single Quotation Factory login the way the web app does.
