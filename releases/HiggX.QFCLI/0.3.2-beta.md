# Quotation Factory CLI v0.3.2-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.3.2-beta - 2026-09-01

### Fixed
- **Shared Auth0 API audience.** The built-in `dev` and `uat` environments now request tokens for the existing shared Auth0 API audience (`https://api.rhodium24.io`) while continuing to call their environment-specific backend hosts. Newly created M2M service accounts can authenticate in dev/UAT without an explicit `--audience` override.
- **Authentication test isolation.** Token-cache tests no longer read credentials from the developer's real QFC profile.
