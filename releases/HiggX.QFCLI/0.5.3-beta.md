# Quotation Factory CLI v0.5.3-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.5.3-beta - 2026-11-21

### Added
- **MCP `support` surface — Customer Success over `qfc mcp`.** The customer-facing Interkwam Messenger is now exposed as `cs_*` MCP tools so an agent can self-serve and escalate:
  - Read: `cs_list_updates`, `cs_get_update`, `cs_search_kb`, `cs_get_article`, `cs_list_conversations`, `cs_get_conversation`, `cs_notifications`.
  - Write (require `--allow-writes`): `cs_start_conversation`, `cs_reply` (both accept product context and an optional KB-grounded AI answer), `cs_mark_update_read`, `cs_acknowledge_emergency`.

  It's a new `support` surface (contributor tier), so `--access contributor`, `--access all`, or `--surface support` include it; the tools refuse when the surface is out of scope, and writes respect `--allow-writes` like `call_api`. Auth is **Auth0** (the caller's own identity — not Entra, which is Interkwam's separate agent/admin MCP): on stdio the tools use the per-service Interkwam token bucket (`qfc --service interkwam auth login`); on the HTTP transport the forwarded caller token is used and must be a Messenger-audience token.
