# Quotation Factory CLI v0.0.6-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.0.6-beta - 2026-08-19

### Fixed
- Updated working-step skill docs for the 2026-08-18 API change that keys working steps by `bomItemActivityId` (working steps are now BoMItem *activities*). Affects `qf-add-working-step`, `qf-analyze-drawing`, `qf-bom-item`, and `qf-cli`:
  - Add working step: `POST .../workingsteps` → `POST .../workingsteps/insert` with body `{boMItemIds, workingStepType, formData}`.
  - New `POST .../workingsteps/update` (body `{bomItemAndActivityIds, workingStepType, formData}`) to edit an existing step.
  - Delete/production-order/forms/resource endpoints and manual cost/time bodies now use `bomItemActivityId`; the `/forms` endpoint takes an activity id in its path (zero-GUID for a new step).
