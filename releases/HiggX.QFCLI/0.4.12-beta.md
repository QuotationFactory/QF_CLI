# Quotation Factory CLI v0.4.12-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.4.12-beta - 2026-11-20

### Changed
- **Document Exchange API (`--service docsexchanger`) synced with the live dev/uat spec.** Verified the API is still served same-host at `api-{dev,uat}.rhodium24.io/docsexchanger` (it has *not* moved to a dedicated domain — the spec declares no alternate `servers`, and no `docsexchanger-*`/`dx-*` subdomain resolves). Picked up the broker's current surface:
  - `qf-scsn` skill gains `POST /messages/{id}/validate` (re-validate a message's UBL content) and `POST /messages/{id}/retry` (retry a failed inbound message), and drops the removed `agents/{id}/migrate-from/{legacyAgentId}` endpoint.
  - New `MessageTrace` tag — the super-admin `GET /docsexchanger/v1/system/message-trace[/agents]` diagnostic — is documented in `qf-scsn` and mapped to the MCP `system` surface (`SurfaceMap`), so it is scoped to system-tier callers rather than falling back to the shared base surface.
