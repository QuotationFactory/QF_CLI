# Quotation Factory CLI v0.0.8-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.0.8-beta - 2026-08-21

### Fixed
- `api post/put` now auto-wraps a bare `thickness` form value into the `QuantityDto` object the API expects. `--form "geometryFiles[0].thickness=8"` is sent as `{"value":8,"unit":"mm","quantityType":"Length"}` instead of a plain number, which previously returned an opaque HTTP 500 (`Error converting value N to type QuantityDto`) and could not be hand-written via `--form` under PowerShell 5.1 (inner quotes were stripped). Values already given as a JSON object, or non-numeric values, are passed through unchanged.

### Changed
- `qf-upload-geometry` skill: corrected the `thickness` field type to `QuantityDto` (was documented as a string), and documented that the upload-time `comment` field does not populate the readable BOM item comment — use `PUT .../items/{bomItemId}/comment` after upload.
