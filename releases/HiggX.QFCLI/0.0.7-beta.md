# Quotation Factory CLI v0.0.7-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.0.7-beta - 2026-08-21

### Added
- `--output` / `-o` flag on `api get/post/put/delete` to write the raw response body directly to a file. Streams bytes verbatim (no text decoding), so it is safe for binary responses such as the quotation PDF, UBL/SCSN document bundles, and project zip exports, and avoids buffering large JSON responses in memory.

### Fixed
- Binary API responses (PDF, zip, images) are no longer silently corrupted. `api get/post/put` and `api batch` previously decoded every response as UTF-8 text, replacing non-UTF-8 bytes with `U+FFFD` and permanently damaging binary content. Binary responses without `--output` now fail fast with a clear `BINARY_RESPONSE` error naming the content-type and size, instead of emitting a broken file. `api batch` returns a per-operation error pointing at `api get --output`.
