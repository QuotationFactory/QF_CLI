# Quotation Factory CLI v0.4.11-beta

This repository stores release metadata and downloadable assets only. Source code is built from Azure Repos.

Assets:
- qfc-cli.zip: cross-platform bundle with binaries, skills, and setup docs.
- qfc-win-x64.zip: Winget-compatible portable Windows package.
- qfc-skills.zip: agent skills for installation with qfc skills update.
- SHA256SUMS.txt: SHA256 checksums for release assets.

Release notes:

## 0.4.11-beta - 2026-11-20

### Added
- **`qfc serve` also shows the Manufacturing Toolkit UI.** A second listener (default `http://localhost:5200`, `--mtk-port`; `--no-mtk` to skip) fronts the toolkit web app: `/api` goes to the toolkit API with your own bearer token added by the proxy (the page never holds a token), `/.auth/me` is answered locally, and the page gets the same kind of context tracking as the QF UI. `qfc context` (new `--app qf|mtk`) now also reports, for the toolkit: the party chosen in its party switcher, the open `caseId`, `jobId` (Drawing to 3D), `weldingCaseId` and `page`, plus the `projectId` / `bomItemId` the open case was imported from (from the case's `externalReference`). `--mtk-ui-url http://localhost:5173` serves the app from a local `npm run dev` instead of the deployed host.
- Needs the toolkit change that lets the app skip its own sign-in behind the proxy, and an app shell that can be fetched with a token (a local dev build, or the toolkit's `/qfc-shell.html`); without those the page says what is missing.
